# Converter skills: reference

Every one of these 4 items, with its options, as APEX's code defines them. Written from the code; the user guide teaches their use.

## `eclipse`

Eclipse decks (E100/E300, `.DATA`): read, and converted to APEX cases on `eclipse`.


## `ert`

ERT cases (`.ert`): to APEX cases (`apex ert convert`) and back (`apex ert export`).


## `opm_flow`

OPM Flow decks (`.DATA`): read, and converted to APEX cases on `opm_flow`.


## `pet`

PET configurations (`.toml`): to APEX cases (`apex pet-import`) and back.
